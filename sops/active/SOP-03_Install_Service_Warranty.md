# Install / Service / Warranty Scheduling

## Trigger
Customer requests installation, assembly, on-site service, or warranty work. Often paired with a freight delivery (see Case 3: delivery + install).

## Routing
Primary lane: **Install / Service / Warranty**.
When an email contains BOTH freight delivery coordination AND install scheduling, the **primary lane is Install / Service / Warranty** because it has the longer lead time and a dependency on delivery completing first. Note **Shipping CS (SOP-02)** as the **secondary** lane. One email, one primary — do not split into two workflows.

## Handling
1. Confirm the equipment + delivery status (install must be scheduled AFTER confirmed freight delivery date).
2. Capture site readiness: floor space, power, ceiling height, access/stairs.
3. Offer install scheduling windows from the service calendar; sequence install to follow delivery.
4. For warranty work, capture serial #, proof of purchase, and fault description.

## Draft tone
Coordinating, sets the delivery-then-install sequence clearly. Draft-only.
