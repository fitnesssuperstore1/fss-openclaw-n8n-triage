# Org Chart — Role → Current Holder (CONTROLLED)

> Controlled source of record for WHO currently holds each approver role. The
> triage system resolves an approver ROLE to its current holder from this table
> at runtime — no person is ever hardcoded in code, skills, or fixtures. When a
> role holder changes, update this document only; nothing in the codebase changes.
>
> In this sandbox the holder is a role mailbox that forwards to the current
> holder; in production it maps to the named individual per HR.
