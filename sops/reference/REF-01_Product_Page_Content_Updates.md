# Product Page / Ecommerce Content Update Process (REFERENCE)

> Reference SOP. Provides context for the Product Content lane. Does NOT override Active routing SOPs.

## Trigger
An **internal team member** reports outdated product page specs, images, pricing, or descriptions on Shopify. This is an internal content task, not a customer support email.

## Routing
Primary lane: **Product Content / Ecommerce**. No customer-facing draft needed; create an internal task.

## Handling
1. Capture the affected product URL/SKU and the specific incorrect content (spec, image, copy).
2. Create a Product Content task with screenshots and the corrected values/source.
3. Assign to the Ecommerce team for Shopify update; note SEO/redirect implications if URL changes.
4. No external email; internal acknowledgement only.

## Note
Because this is Reference, it informs lane assignment but the Master Policy (Active) controls the final routing decision.
